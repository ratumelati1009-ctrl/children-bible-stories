# 🌟 Bible Stories for Little Hearts — Trilingual Children's Bible

A children's Bible storybook (ages 5–13) with **10 stories**, each presented in:
**English • ትግርኛ (Tigrinya) • አማርኛ (Amharic) • ግዕዝ (Ge'ez verse)**

## 📂 What's in this project

| File | What it is |
|------|-----------|
| `Trilingual_Bible_Stories_for_Kids.md` | The full manuscript — all 10 stories in 4 languages, with lessons & discussion questions. **Edit this file** to change content. |
| `Trilingual_Bible_Stories_for_Kids.html` | Print-ready / e-reader edition, styled for the Fidel script. Open in a browser → Print → Save as PDF. |
| `build_html.py` | Regenerates the HTML from the Markdown. Run after editing the manuscript. |
| `QUALITY_CHECKLIST.md` | Everything to verify before publishing (translation review, design, legal, store setup). |
| `marketing/SALES_STRATEGY.md` | Realistic plan to maximize orders toward your 10k–20k goal. |

## 📖 The 10 stories
1. God Makes the World (Creation)
2. Noah and the Big Boat
3. David and the Giant (David & Goliath)
4. Daniel and the Lions
5. Baby Jesus is Born (The First Christmas)
6. Jonah and the Big Fish
7. The Good Shepherd (The Lost Sheep)
8. Jesus Feeds the Crowd
9. Jesus Loves the Children
10. Jesus is Alive! (The First Easter)

## 🔧 To regenerate the HTML after editing
```bash
python3 build_html.py
```

## ⚠️ Before you publish
1. **Get the Tigrinya, Amharic, and Ge'ez text reviewed by native speakers / a liturgical reviewer.** The translations here are a strong first draft but need expert confirmation — this is the #1 thing protecting your reviews.
2. Add **illustrations** and a professional **cover**.
3. Export **EPUB** (Kindle) and **PDF** (print), with fonts embedded.
4. Follow `QUALITY_CHECKLIST.md`, then execute `marketing/SALES_STRATEGY.md`.

*This is a starting product you can build on — not final, publish-ready files. The honest path to big sales is quality + reviews + church/school bulk orders + diaspora social video.*
