# Honesty & Truth — Volume 2

**20 Bible Stories with Moral Lessons** for ages 6–19.

Trilingual: **English • ትግርኛ (Tigrinya) • አማርኛ (Amharic)**

Each story is told across multiple illustrated "scene" pages, with a moral lesson
in all three languages and a Bible reference on every page.
