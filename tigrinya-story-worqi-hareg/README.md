# ወርቂ ሓረግ (Golden Thread) — A Long-Form Story in Tigrinya

An original, 30+ page story written in **Tigrinya** (ትግርኛ), following the life
journey of **ሳባ (Saba)** — a curious girl from a small highland village who,
through education, perseverance, and her family's sacrifice, becomes a doctor

## 🖨️ How to get a PDF

The sandbox that produced this repo has no Ge'ez font installed, so a PDF could
not be generated there without the text turning into empty boxes. Instead, use
the print-ready HTML, which loads a Ge'ez web font in your browser:

1. Download / open **`ወርቂ-ሓረግ.html`** in any web browser.
2. Press **Ctrl + P** (Windows/Linux) or **Cmd + P** (Mac).
3. Set **Destination** to **"Save as PDF"**.
4. Click **Save**.

You'll get a clean, correctly-rendered Tigrinya PDF of 30+ pages.
