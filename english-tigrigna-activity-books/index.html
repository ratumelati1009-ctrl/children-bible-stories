Each book has the Bible story, memory verse (ICB), comprehension, sequencing, word search, crossword, matching, colouring, count & colour, "What Would You Do?" scenarios, spot-the-difference, maze, dot-to-dot, craft, bookmarks, secret code, prayer, reflection and a completion certificate.

To print: open a book and use the 🖨️ Print / Save PDF button (or Ctrl/Cmd + P) → "Save as PDF", A4, margins: None. Ready-made PDFs are in the pdf/ folder.
